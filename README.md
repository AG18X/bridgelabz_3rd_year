## ✅ Best Programming Practices Followed

- All values stored in variables (no hardcoding of inputs or outputs)  
- Proper naming conventions (`camelCase` for variables, `PascalCase` for classes)  
- Each question in a **separate `.java` file** with a meaningful class name  
- Proper indentation and formatting maintained  
- User input handled using `Scanner` class wherever required
